# MEGASTRATA v3.0 (Minecraft 1.20.1 Forge) — Оригинальная версия + Панельный Гигахрущ

Возвращена архитектура и атмосфера первоначальной версии мода с добавлением сквозного **Панельного Гигахруща** и широких переходных **Снежных равнин между зданиями**:

1. **Убрана смена дня и ночи, возвращён постоянный белый туман:** зафиксированное время (`fixed_time: 6000`) и густой холодный бело-серый туман (`ViewportEvent.ComputeFogColor` / `RenderFog`), скрывающий дальние границы мегаструктуры.
2. **Возвращены все старые структуры из первой версии:** гигантские полые колонны с лифтами, межслойные перекрытия каждые 400 блоков, мосты каждые 80 блоков, все 8 оригинальных мегаструктур, трёхплатформенные станции, квартиры («Окна в чужую жизнь»), насосы Мёртвого океана, заводские линии и редкие аномалии.
3. **Панельный ГИГАХРУЩ, пронизывающий всю мегаструктуру от и до (`Y = -1960 .. +1920`):**
   - Бесконечные панельные многоэтажки со швами между бетонными плитами, окнами, балконами и внешними блоками;
   - Внутри — настоящие советские подъезды (снизу покрашенные сине-зелёной краской, сверху побеленные), лестничные клетки, клапаны мусоропровода (`hopper`), тусклые фонари и жилые квартиры;
   - Висячие панельные блоки на тонких сваях и трубах с натянутыми проводами в белом тумане.
4. **Огромная Снежная Равнина как переходный этап между зданиями:**
   - Каждые 1024 блока по горизонтали между гигантскими массивами Гигахруща/Мегаструктуры простирается снежная равнина шириной **464 блока** (`X/Z = 560..1024`), соединяющая соседние комплексы зданий;
   - На этих снежных равнинах между зданиями спавнятся структуры из Верхнего мира (иглу, аванпосты, разрушенные порталы, дома, палатки, колодцы и редкие заброшенные русские деревеньки).

## Команды для телепорта в игре
- Внутри **Массива Гигахруща и оригинальной Мегаструктуры**:
  `/execute in megastrata:megastrata_dim run tp @s 120 120 120`
- На **Переходной Снежной Равнине между зданиями Гигахруща**:
  `/execute in megastrata:megastrata_dim run tp @s 600 10 600`
